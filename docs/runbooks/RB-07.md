# RB-07 — Notification outage

Steps: detect → contain → recover → verify → communicate (edge-case doc §9).

Detect outbox lag >5min or channel errors. Contain: turn the channel flag off; in-app continues. Recover: restore; relay drains as digests. Verify: outbox lag <60s. Communicate: admin banner; work from the in-app queue.

Rehearsed: before submission and in pilot week 1.
