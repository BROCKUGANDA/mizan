# RB-08 — Demo-day failure

Steps: detect → contain → recover → verify → communicate (edge-case doc §9).

Detect anything on stage. Contain: switch to offline laptop profile; recorded walkthrough as backup. Recover: Reset, resume from last checkpoint. Communicate: one sentence + show the mode banner — degraded modes are part of the story.

Rehearsed: before submission and in pilot week 1.
